# 피처 설계 노트

## 문제 정의

- 입력값 `X`: 계약 금액, 시세, 등기부 권리관계, 건축물 상태, 임대인·중개사 정보, 특약 텍스트, 판례 기반 위험 신호
- 출력값 `y`: `0=안전`, `1=주의`, `2=위험`
- 최종 사용자 출력: 위험 점수, 등급, 위험 근거

## 핵심 파생 피처

| 피처 | 의미 | 위험 해석 |
|---|---|---|
| `jeonse_ratio` | 보증금 / 추정 시세 | 90% 이상이면 깡통전세·보증보험 거절 가능성이 커짐 |
| `debt_ratio` | (보증금 + 근저당 + 선순위채권) / 추정 시세 | 시세에 근접할수록 보증금 회수 여력이 낮음 |
| `seizure`, `provisional_seizure` | 압류·가압류·가처분 | 소유권/처분권 침해 가능성 |
| `trust_registered` | 신탁등기 | 신탁원부와 임대 권한 확인 필요 |
| `illegal_building` | 위반건축물 | 대출·보증·이용 제한 가능성 |
| `broker_unregistered` | 무등록 중개 또는 중개보조 단독 진행 | 공인중개사법상 위험 |
| `broker_advertising_issue` | 광고와 실제 권리관계 불일치 | 허위·과장 광고 가능성 |
| `guarantee_insurance_available` | 보증보험 가능 여부 | 거절 조건이면 회수 위험 증가 |
| `combined_text` | 판례·특약·사용자 상황 텍스트 | 사기, 기망, 신탁, 압류, 위조 등 텍스트 신호 |

## 모델 구조

`ColumnTransformer`로 숫자형, 범주형, 불리언, 텍스트 피처를 결합한 뒤 `BaggingClassifier`에 입력한다.

- 숫자형: median imputation + standard scaling
- 범주형: one-hot encoding
- 불리언: 0/1 passthrough
- 텍스트: TF-IDF
- 모델: BaggingClassifier + DecisionTreeClassifier

## 규칙 보정

모델 예측만으로는 실제 사용자가 입력하는 새 사례의 권리관계 위험을 과소평가할 수 있다. 따라서 최종 점수는 Bagging 모델 확률과 명시적 권리관계 규칙을 결합한다.

- 모델 점수 성분: 클래스 확률 기반
- 규칙 점수 성분: 전세가율, 부채비율, 압류, 신탁, 위반건축물, 보증보험 불가 등
- 최종 점수: 모델과 규칙을 혼합하되, 명백한 권리침해 신호는 하한 점수로 반영
