## 테스트 범위

- 데이터 로딩: 원본 판례 CSV 900건 이상 로딩 확인
- 파생 데이터 생성: 모델 필수 컬럼과 `안전/주의/위험` 라벨 포함 확인
- 모델 구조: `sklearn.ensemble.BaggingClassifier` 사용 확인
- 스코어링: 고위험 입력과 저위험 입력의 점수/등급 차이 확인
- 현실형 사례: 데이터셋에 없는 36개 사용자 시나리오 기준 점수 범위 확인
- 반례 검증: 낮은 전세가율+압류, 낮은 부채비율+신탁, 높은 전세가율 단독 경계 입력 확인
- 현장패턴 검증: 임대인 명의 불일치, 전입신고 지연/당일 근저당, 안전한 대리계약 확인
- 자연어 신호 검증: 사용자 설명 문장에서 보호요건 완료 신호와 신탁·압류·체납·이중계약·보증보험 불가 치명 신호를 피처로 반영하는지 확인
- 구어체 입력 검증: 체크박스를 누락하고 상황란에만 쓴 압류/신탁/보증보험 불가 문장을 위험 또는 주의로 보정하는지 확인
- 계좌·건축물 텍스트 검증: 계약금 계좌 명의 불일치, 불법증축·쪼개기, 법인 임대인 개인계좌, 계약금 선입금 압박 문장을 보정하는지 확인
- 권원·등기 텍스트 검증: 임대인 동의 없는 전대차, 임차권등기명령 말소 미확인, 미등기 신축, 가계약금 환불불가 문장을 보정하는지 확인
- 권리순위·경매 텍스트 검증: 전입세대열람 미제공, 선순위 임차보증금 총액 불명, 경매개시결정, 공매 예고, 매매·전세 동시진행, 잔금 당일 대출 선행 요구 문장을 보정하는지 확인
- 정상 계약 사례: 일부 안전 시나리오에서 Bagging 모델 단독 예측도 `안전`인지 확인

## API 및 웹 시연 검증

서버:

```bash
PYTHONPATH=src .venv/bin/python scripts/run_web.py --host 127.0.0.1 --port 8765
```

검증 결과:

- `GET /api/health`: 200, `model_exists=true`
- `GET /static/risk-illustration.svg`: 200, `image/svg+xml`
- `POST /api/predict`: 200, 안전 전세 예시 `안전 15.5점`, 고위험 기본 예시 `위험 93.0점`, 경매개시결정 텍스트-only 예시 `위험 78.0점`, 선순위 보증금 총액 불명 예시 `위험 72.0점`
